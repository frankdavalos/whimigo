# A Player's identity is their Mascot; there are no profiles or names

A child joins a Session by tapping an animal. That Mascot is the child's identity from then on, and Progress is stored against it. There is no profile to create, no name to type and nothing to log in to.

We considered named profiles set up by an adult and rejected them: they need a keyboard, a setup step before first play, and a screen for managing them, all for children who cannot read their own name on a small label. We considered having no persistent identity at all (four anonymous coloured Seats) and rejected that because Stars and Achievements mean little if they belong to nobody.

## Consequences

- Progress is keyed by Mascot id in the save document. Mascot ids are permanent; renaming one orphans its Progress.
- Two children who both want the fox must settle it themselves. Within a Session a Mascot can hold only one Seat.
- A visiting friend picks any unused Mascot and adds to its Progress.
- The roster needs more Mascots than there are Seats, so that a family of four plus visitors has a choice. Eight is the working number.
- An optional adult-entered name per Mascot could be added later without changing this decision.
